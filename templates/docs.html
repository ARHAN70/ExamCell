System Documentation

Welcome to the ExamCell AI v2.1 official documentation. This platform is designed to automate the complex process of university examination management, from defining room layouts to generating anti-cheat seating arrangements.

Core Features

Smart Allocation Logic

The system uses a "Non-Adjacent" algorithm. It ensures that two students from the same department never sit next to each other.

Visual Campus Map

Create blocks, floors, and rooms. Use the Visual Editor to drag and drop benches, defining the exact capacity of every room.

QR Code Stickers

Generate printable stickers for desks. Each sticker contains student info and a scanable QR code for instant identity verification.

Bulk CSV Import

Upload hundreds of students in seconds using Excel or CSV files. The system automatically sorts them into Programs and Semesters.

User Guide

1

Campus Infrastructure Setup

Before allocating seats, you must define the physical space.

  • Go to Campus page.
  • Click "Add Building" to create a Block.
  • Click "Manage Structure" to add Floors and Rooms.
  • Use the Room Editor to draw the bench layout (e.g., 5 rows x 4 columns).
2

Manage Student Data

Ensure student data is accurate for allocation.

  • Go to Programs to define courses (e.g., B.Tech CSE, MBA).
  • Go to Students page.
  • Use "Bulk Upload" to upload an Excel file.
  • Format: The Excel file must have columns: Name, Roll No, Reg No.
3

Run Allocation Algorithm

The core function of the system.

1. Select the Programs (e.g., B.Tech Sem 3 & BBA Sem 1).
2. Select "Odd" or "Even" semester exam.
3. Click "Start Allocation".
4. The system will mix students and fill rooms automatically.

4

Publish & Print

Finalize the process.

  • Once satisfied with the preview, click "Publish Timetable".
  • This saves the snapshot to the database.
  • Go to "Exam Timetable" to view history.
  • Click "Print Stickers" to generate the PDF for sticking on desks.
