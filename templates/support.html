Frequently Asked Questions

General
What is ExamCell AI used for?
It is a web-based automated examination management system designed to handle seating arrangements, room mapping, and student data management for universities.
Does this system require an internet connection?
No, if installed on a local server (localhost), it works completely offline. However, cloud-hosted versions require internet access.
Is there a limit to the number of students?
There is no hardcoded limit. The system can handle thousands of students as long as your database and server hardware can support it.
Data & Setup
What file formats are supported for bulk upload?
We support .csv and .xlsx (Excel) files. Ensure your file has headers like 'Name', 'Roll No', and 'Reg No'.
Can I edit a room layout after creating it?
Yes! Go to the Campus page, select the block, find the room, and click "Editor". You can drag, drop, or remove benches anytime.
How do I delete specific students?
Currently, you can use the "Delete All" button for a specific program. Individual student deletion will be added in a future update.
What happens if I upload duplicate student data?
The system uses unique IDs. If a Roll Number matches an existing record, the upload might be skipped or duplicated depending on settings. It is best to clear old data first.
How do I handle students with backlogs?
Create a separate "Program" named "Backlog Exam" and upload the list of those students there. Select this program during allocation.
Allocation Logic
How does the "Non-Adjacent" logic work?
The algorithm alternates students from different selected programs (e.g., Program A student, then Program B student) to ensure neighbors are taking different exams.
Can I manually change a seat after allocation?
Currently, the system is fully automated to prevent bias. You would need to re-run the allocation to change seats.
What if there are more students than seats?
The allocation process will stop when rooms are full. You should always ensure Total Capacity > Total Students in the Allocation dashboard before running.
Can I run allocation for just one department?
Yes, select only that specific Program in the "Allocation" page checklist. However, the anti-cheat adjacency logic works best with 2+ programs.
How long does the allocation process take?
For a typical dataset of 500-2000 students, the AI algorithm completes the task in less than 2 seconds.
Printing & Technical
How do I delete a published timetable?
Go to the "Exam Timetable" page. You will see a list of published exams. Click the red "Delete" icon to remove it from the history.
How do I scan the student QR codes?
Any standard smartphone camera or QR code scanner app can scan the code. It redirects to a verified student profile page on the system.
Can I resize the stickers?
The system generates a standard HTML/PDF layout optimized for A4 paper. You can adjust the "Scale" in your printer settings dialog box.
Is my data secure?
Yes. Data is stored in a local SQLite database. Passwords are handled securely. For production use, ensure your server has proper firewalls.
Can multiple admins log in at once?
Yes, you can create multiple faculty accounts via the "Sign Up" page. Each admin has full access to the system.
What if a room is under maintenance?
Simply go to the Campus editor and delete the benches from that room (or set capacity to 0). The algorithm will automatically skip it.
How do I reset my password?
Currently, there is no UI for password resets for security reasons. Please contact the database administrator to manually reset credentials.
